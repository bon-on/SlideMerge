# Slide Merge

A compact sliding merge puzzle (2048-style) built with Flutter for iOS, Android, and web.

## Gameplay

Every tile is a code-drawn sea creature that evolves when twins merge:
Plankton (2), Shrimp, Starfish, Clownfish, Pufferfish, Jellyfish, Crab, Octopus,
Sea Turtle, Dolphin, Whale (2048), Narwhal, Sea Dragon and the Star Whale
(16384+). The value stays visible as a small badge.

- **Modes**: Classic 4x4 (default, 90% / 10% spawns, tense) and Relaxed 5x5 (roomier, 82% / 18% spawns).
- **Twist - undo charge**: you hold one undo charge. Spend it to take back your last move; it recharges every 20 merges.
- **Controls**: swipe (any deliberate drag of 24 px or more), arrow keys, or WASD. `Z` / `U` undoes.
- **Best score** is saved locally per mode.
- Classic scores can be submitted to the opt-in leaderboard at game over.

## Progress between runs

- **Missions**: three per run (make a creature, merge N times, combo, score,
  moves); each gives bonus XP. Targets scale with player level and board
  size: a Lv1 player gets goals one normal run reaches (e.g. make a 32, merge
  10 times, combo x2, score 500); harder ones unlock with level.
- **Player level**: XP = score / 20 + mission XP + 10 for runs of 10+ moves.
  Levels unlock board themes: Lagoon (Lv1), Coral Reef (Lv3), Polar Sea (Lv6),
  Moonlit Deep (Lv10). Pick one in the album.
- **Creature album**: every creature you make is recorded; unknown ones show
  as silhouettes. A new creature gets a big celebration.
- **Run summary** at game over: score, best, top creature, XP and level bar.
  Enter plays again, Esc closes it. Restarting mid-run also banks its XP.
- Progress is stored locally under `slide_merge_progress_v1`; best scores keep
  their `best_score_<mode>` keys.

## Development

```sh
flutter pub get
flutter run -d chrome
flutter analyze
flutter test
```

Game rules live in `lib/game_logic.dart` (widget-free, injectable `Random`) and are unit tested in `test/game_logic_test.dart`.

## Local Web Build

```sh
flutter build web --release --base-href /SlideMerge/
```

GitHub Pages deploys from `.github/workflows/deploy-pages.yml`.

## CrazyGames Web Build

`tool/build_crazygames.sh` builds `build/crazygames/` and the upload zip `build/slide-merge-crazygames.zip` (no hub link, leaderboard or ads; SDK gameplay events). See `docs/crazygames.md`.

## GamePix Web Build

`tool/build_gamepix.sh` builds `build/gamepix/` and the upload zip `build/slide-merge-gamepix.zip` (SDK-free; no hub link, leaderboard or ads). See `docs/gamepix.md`. Roboto is bundled in `assets/fonts/` (see `assets/fonts/Roboto_LICENSE.txt`) so web builds make no font requests.

## Tutorial

A short how-to-play card appears on first launch (skip with Esc or the Skip button). The `?` button in the header reopens it.

## Sound

Sound effects (slide, merge, combo, new creature, mission, level up, undo,
game over) and a calm, bubbly music loop share one sound on/off button next to
the `?` button; the choice is remembered via `sound_muted_v1` and CrazyGames
muting (including live setting changes) is respected. On web the music starts
after the first click or key press and pauses while the tab is hidden. All
audio is generated by `tool/generate_sounds.py` (Python stdlib, deterministic),
no third-party audio. Regenerate it with:

```sh
python3 tool/generate_sounds.py
```
